**中文** | [**English**](https://github.com/aji110905/Carpet-Aji-Addition/blob/release/README_en.md)

[fabric-carpet](https://github.com/gnembon/fabric-carpet) 的一个扩展, 增加了许多实用的规则，让您在游玩Minecraft的时候更具乐趣。

## 如何使用

1. 安装Fabric Loader
2. 安装对应Minecraft版本的[Carpet](https://modrinth.com/mod/carpet)
3. 安装对应Minecraft版本的[Carpet Aji Addition](https://modrinth.com/mod/carpet-aji-addition)
4. 进入游戏后输入`/carpet list CAA`查看该扩展添加的所有规则
